# Model credits

Most models are built by `tools/blender/build_models.py` (original work for this game).
These come from free CC0 (public domain) packs, converted by `tools/blender/import_cc0.py`
(one plain colour per face so the game's painted shader can repaint them):

| Model | Source | Licence |
|---|---|---|
| car_hatchback (sedan), car_jeep (suv), car_van (van), tractor | Kenney, Car Kit 3.1, https://kenney.nl/assets/car-kit | CC0 1.0 |
| cow, pig, sheep, dog (Pug) | Quaternius, Farm Animals Pack, https://quaternius.com/packs/farmanimal.html | CC0 1.0 |
