# Spec (lite) — Chapter 4: the stopped clock tower, numbers (roadmap step 24)

> Data: `content/chapters/chapter4_clock.tres`; played after Chapter 3, then the practice loop.

## 5. Acceptance criteria

- **AC-01 The clock maker asks for help.** By the clock tower the clock maker (his own English
  voice) says: "Hello! Oh no! My clock stopped! The numbers fell off!" … "Can you find the
  numbers? One, two, three, four and five!"; he says hello back.
- **AC-02 Find each number, in order.** One at a time: "Find number one!" — the number tiles lie
  around town (park, harbour, square, sea front, lane). Each tile shows the digit on both sides
  plus the same count of dots (shape cue, not only the digit) and glows softly. Clicking it:
  "Number one! One! You found it!", and the tile is collected. First meetings open the
  learning card for the number word.
- **AC-03 The clock works.** The clock maker thanks him and counts to ten with him ("One! Two! …
  Ten!"), a card for *clock*, then "The clock works again! Tick tock! Ding dong!". Remembered
  (`chapter:clock`); the game goes on to the practice loop.
- **AC-04 Never stuck.** The usual hint ladder applies to each number (hint line, glow
  brightens). Characters have no collision, so a character never blocks the hero's path.

## Out of scope

Numbers six to ten as things to find (counted aloud only); the clock face animation.
