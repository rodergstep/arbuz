# Contract — content resources (chapters)

Chapters are data (ADR-0004): `content/chapters/<id>.tres`, a `ChapterData`
(`game/core/chapter_data.gd`) holding `QuestStep`s (`game/core/quest_step.gd`), run in a scene by
`QuestRunner` (`game/core/quest_runner.gd`). Generated by `tools/build_chapters.gd`; editable in the
inspector.

## ChapterData

| Field | Type | Meaning |
|---|---|---|
| `id` | StringName | chapter id |
| `steps` | Array[QuestStep] | in order |
| `loop` | bool | start again after the last step (practice loop) |
| `loop_line` | String | line key said when it starts again |
| `loop_delay` | float | seconds before it starts again |
| `next_chapter` | String | `res://` path played after this one (prologue → practice loop) |
| `done_key` | String | remembered in the save when finished (e.g. `chapter:prologue`) |

## QuestStep

| Field | Type | Meaning |
|---|---|---|
| `kind` | `GET_IN_CAR` · `DRIVE_TO` · `WALK_TO` · `OPEN_DOOR` · `FIND_OBJECT` · `TALK_TO` · `FERRY` · `COLLECT` | what finishes the step: entering the car; the car reaching the marker (he gets out); the hero reaching the marker or the door question starting; the door opening; clicking the asked thing; the talk with the character at the marker ending; the ferry cutscene ending; every item of a collect step found. New kinds are appended (the `.tres` stores the number) |
| `spots` | Array[Vector3] | marker positions; each loop visit uses the next |
| `start_line` | String | line key said when the step starts (after any learning card) |
| `hint_line` | String | Tygrytsa's idle-hint line key |
| `arrive_line` | String | said on reaching the marker when one more action is needed |
| `talk_id` | StringName | TALK_TO: which conversation the scene plays (`baker_intro`, `baker_thanks`) |
| `word` | StringName | COLLECT: the word of the things to find (one at each spot in `spots`) |
| `count` | int | COLLECT: how many (= number of spots) |
| `homes` | Array[Vector3] | COLLECT: where each found thing goes and stays (animals to the farm); empty = it flies away |
| `find_line` / `found_line` | String | COLLECT: line keys (with `{word}`) for asking and for a single find; empty = chapter 1 defaults |

Line keys refer to `content/voice/lines.csv` (`docs/contracts/voice-lines.md`).

England chapters chain by `next_chapter`: `chapter1_bakery` → `chapter2_balloons` →
`chapter3_animals` → `chapter4_clock` → `chapter5_festival` (the finale) → `england_practice`;
their `done_key`s are `chapter:bakery`, `chapter:balloons`, `chapter:animals`, `chapter:clock`,
`chapter:festival`.

### Talk scripts (`EnglandTown.TALKS`, keyed by `talk_id`)

`who` (main speaker), `lines` (line keys; an entry `[who, key]` lets another friend speak and
wave), optional `say_back` (word he says back, microphone, never judged) with `say_line` (the
prompt; default `talk:say_hello`), `card` (learning card word), `after` (cheer lines) and
`cheer` (the festival's confetti and tune).

## Host API (the scene running a chapter)

`place_marker(pos: Vector3)`, `clear_marker()`, `set_hint(goal: Node3D, line_key: String)`,
`say_when_free(line_key: String)`, `car_position() -> Vector3`, `exit_car()`, `start_find()`, `start_talk(talk_id)`, `play_ferry()`, `start_collect(step)`, and a `marker`
property. The scene reports `notify_car_entered()`, `notify_marker_reached(&"hero"|&"car")`,
`notify_door_question()`, `notify_door_opened()`, `notify_found()`, `notify_talk_done()`, `notify_ferry_done()`, `notify_collected()`.
