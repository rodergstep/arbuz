# Contract — voice lines

**Catalogue:** `content/voice/lines.csv` (`key,uk,en,speaker`; `keep` importer). Keys: `line:*` (Tygrytsa's
instructions), `hint:*`, `door:*`, `card:*`, `thing:*`, `session:*`. Placeholders in either
column: `{word}` (English word), `{Word}` (capitalized), `{a_word}` (with a/an), `{uk_word}`.
`speaker` (optional) names another character whose English uses their own voice (`postman` → Chatterbox cloned from `audio_gen/voices_ref/postman.wav`); their file name hashes `<lang>|<speaker>|<text>`. Ukrainian lines are always Tygrytsa's. An empty `uk` means English only; a line with `uk` is said in Ukrainian + English the first time
its key (or the caller's `first_key`) is met, English only after (`Speech.line`).

**Audio:** `audio/voice/<lang>/<sha1("<lang>|<text>")[:16]>.ogg`, generated by
`audio_gen/generate_voices.py` from the catalogue × every word in the word DB, plus each word and
its `examples_en`. Git LFS. A missing file falls back to OS text-to-speech.

**CLI:** `audio_gen/.venv/bin/python audio_gen/generate_voices.py [--dry-run]`; exit 0; renders
only missing files and removes unused ones.

Rule: a new line in code is a new row here (never an inline string), then re-run the generator.

`words` (optional): narrows a `{word}` template to the words it is used with, as word ids or
`topic:<topic>` (e.g. `topic:colours`); empty = every word. Only the voice generator reads it.
